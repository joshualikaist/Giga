# 04. simple_biped 모델 사양서

> 파일: `models/urdf/simple_biped/simple_biped.urdf` / 설정: `biped_sim/robot_configs.py`
> 목적: "URDF → MuJoCo → 관절 제어 → 서 있기"를 배우기 위한 **가장 단순한 2족 로봇**.
> 실제 로봇 모델로 교체하기 전까지 시뮬레이터 코어를 개발·검증하는 기준 모델(baseline)입니다.

## 1. 구조

```
        측면도 (x → 앞)                      정면도 (y → 왼쪽)

           ┌──────┐                         ┌──────────────┐
           │ base │ 4.0 kg                  │  base_link   │  0.12 × 0.22 × 0.20 m
           │ link │                         │   (몸통)     │
           └──●───┘ ← hip_pitch             └──●───────●───┘  hips: y = ±0.07 m
              \                                │       │
               \ thigh 0.25 m, 1.0 kg       (오른쪽)  (왼쪽)
                ● ← knee                       │       │
               /                               ●       ●     knees
              / shin 0.25 m, 0.8 kg            │       │
             ● ← ankle_pitch                   │       │
          ┌──┴────┐                          ┌─┴─┐   ┌─┴─┐
          └───────┘ foot 0.16 m, 0.3 kg      └───┘   └───┘   feet 0.08 m 폭
          ↑ 발은 발목보다 3 cm 앞으로 나와 있음
```

링크 트리 (관절 순서 = URDF 작성 순서 = MuJoCo 관절/모터 순서):

```
base_link
├── left_hip_pitch    → left_thigh  → left_knee  → left_shin  → left_ankle_pitch  → left_foot
└── right_hip_pitch   → right_thigh → right_knee → right_shin → right_ankle_pitch → right_foot
```

## 2. 링크 (질량·형상·관성)

| 링크 | 질량 [kg] | 형상 (URDF 전체 길이) | COM (링크 좌표계) [m] | Ixx / Iyy / Izz [kg·m²] |
|---|---|---|---|---|
| base_link | 4.0 | box 0.12 × 0.22 × 0.20 | (0, 0, 0) | 0.0294667 / 0.0181333 / 0.0209333 |
| *_thigh | 1.0 | cylinder r=0.03, L=0.25 | (0, 0, −0.125) | 0.00543333 / 0.00543333 / 0.00045 |
| *_shin | 0.8 | cylinder r=0.025, L=0.25 | (0, 0, −0.125) | 0.00429167 / 0.00429167 / 0.00025 |
| *_foot | 0.3 | box 0.16 × 0.08 × 0.03 | (0.03, 0, −0.015) | 0.0001825 / 0.0006625 / 0.0008 |
| **합계** | **8.2** | | | |

관성은 모두 균일 밀도 도형 가정 (`scripts/inertia_calc.py`).

## 3. 관절

| 관절 | 부모 → 자식 | origin (부모 기준) [m] | 축 | 범위 [rad] (deg) | 최대 토크 [N·m] | damping | friction |
|---|---|---|---|---|---|---|---|
| left_hip_pitch | base_link → left_thigh | (0, 0.07, −0.10) | +y | −1.57 ~ 0.52 (−90° ~ 30°) | 20 | 0.1 | 0.02 |
| left_knee | left_thigh → left_shin | (0, 0, −0.25) | +y | 0 ~ 2.36 (0° ~ 135°) | 20 | 0.1 | 0.02 |
| left_ankle_pitch | left_shin → left_foot | (0, 0, −0.25) | +y | −0.79 ~ 0.79 (±45°) | 10 | 0.1 | 0.02 |
| right_* | (y 부호만 반대) | (0, −0.07, −0.10) … | +y | 동일 | 동일 | 동일 | 동일 |

URDF `velocity="10.0"`도 적혀 있지만 MuJoCo는 이 값을 무시합니다 ([03](03_urdf_and_mujoco.md) 참고).
빌더가 추가하는 것: 관절마다 `armature = 0.01 kg·m²`(모터 회전자 관성), 토크 모터(`ctrlrange` = 최대 토크).

### 부호 규약 (오른손 법칙, +y축 = 왼쪽 방향 기준)

| 관절 | (+) 방향 | (−) 방향 |
|---|---|---|
| hip_pitch | 다리가 **뒤로** | 다리가 **앞으로** (굽힘) |
| knee | 무릎 **굽힘** | (0이 완전히 편 상태, 음수 불가) |
| ankle_pitch | 발끝이 **아래로** | 발끝이 **위로** |

> 실제 로봇의 모터 부호와 다를 수 있습니다. 실제 로봇 URDF로 교체할 때 t04의 뷰어 슬라이더로 하나씩 확인하세요.

## 4. 기본 자세 (home)

`hip = −a, knee = 2a, ankle = −a` 이면 (허벅지와 정강이 길이가 같으므로)
**발목이 고관절 바로 아래**에 오고 **발바닥이 수평**이 됩니다. `a = 0.4 rad`(≈ 23°)를 사용합니다.

| 항목 | 값 | 출처 |
|---|---|---|
| 관절각 | hip −0.4, knee 0.8, ankle −0.4 rad | `robot_configs.SIMPLE_BIPED.home_pose` |
| 몸통 높이 (발바닥 1 mm 위) | 0.5915 m | 빌더가 자동 계산 (해석해 0.5905 m + 1 mm) |
| 서 있을 때 몸통 높이 | 0.5877 m | t06 (접촉으로 살짝 내려앉고 관절이 처짐) |
| 무게중심 (world) | x = +0.024, z = 0.41 m | 다리가 앞으로 굽어 있어 몸통보다 약간 앞 |
| 지지 다각형 (두 발) | x: −0.05 ~ +0.11, y: −0.11 ~ +0.11 m | 무게중심이 안쪽에 있으므로 정적으로 안정 |
| (참고) 다리를 쭉 편 경우 몸통 높이 | 0.631 m | |

## 5. 제어 게인 (관절 PD)

| 관절 | Kp [N·m/rad] | Kd [N·m·s/rad] |
|---|---|---|
| hip_pitch, knee | 100 | 4 |
| ankle_pitch | 80 | 2 |

근거: 서 있는 로봇은 발목을 축으로 한 역진자이고, 넘어지려는 중력 강성은 `m·g·h ≈ 8.2 × 9.81 × 0.41 ≈ 33 N·m/rad`.
두 발목의 강성 합이 이보다 충분히 커야 합니다. 실측(t06과 같은 조건, 앞으로 0.1 s 밀기):

| 발목 Kp (hip/knee Kp) | 가만히 서기 | 20 N 밀기 | 40 N 밀기 |
|---|---|---|---|
| 30 (80) | ✅ | ❌ 넘어짐 | ❌ |
| 60 (80) | ✅ | ✅ | ❌ |
| **80 (100) ← 채택** | ✅ | ✅ | ❌ |
| 100 (200) | ✅ | ✅ | ❌ |

**40 N은 어떤 게인으로도 못 버팁니다.** 몸 전체를 앞발 끝(x = 0.11 m)을 축으로 도는 하나의 강체로 근사하면
(발끝 축 기준 관성 1.80 kg·m², 몸통 높이 0.588 m에서 밀기):

| | 값 |
|---|---|
| 넘어가는 데 필요한 에너지 (무게중심이 발끝 바로 위까지 올라가는 위치에너지) | 0.75 J |
| 20 N × 0.1 s 밀기가 주는 회전 운동에너지 | 0.38 J → 버팀 |
| 40 N × 0.1 s 밀기가 주는 회전 운동에너지 | 1.5 J → 넘어짐 |

(강체 근사이므로 대략적인 추정이지만 시뮬레이션 결과와 일치합니다.)
관절을 아무리 단단하게 해도 발이 작으면 소용없고, **발을 내딛거나(stepping) 상체를 써서 균형을 잡는 제어**가 필요합니다 → Phase 8.

서 있을 때 실측 토크: knee ≈ −2.5 N·m, ankle ≈ +0.8 N·m, hip ≈ 0 (각 다리). 정상 상태 오차: knee 약 1.4° (중력 보상이 없어서).

## 6. 한계 (의도된 단순화)

| 한계 | 영향 | 해결 시점 |
|---|---|---|
| hip roll / ankle roll 없음 | 좌우로 체중 이동 불가 → **3D 보행 불가** (옆으로 밀면 버티는 힘이 다리 구조 강성뿐) | Phase 4: 12-DoF 모델 |
| hip yaw 없음 | 방향 전환 불가 | Phase 4 |
| 균일 밀도 도형 | 실제 로봇의 질량 분포와 다름 | Phase 7: CAD 기반 URDF |
| 이상적인 모터 (지연·노이즈·속도한계 없음) | 시뮬레이션이 실제보다 낙관적 | Phase 4 |
